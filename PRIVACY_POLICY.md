# Kebijakan Privasi TodO

Terakhir diperbarui: 2 Oktober 2026

TodO menyimpan tugas dan pengaturan secara lokal di perangkat. Aplikasi tidak
memerlukan akun dan tidak mengirim data tugas ke server pengembang.

## Data yang disimpan

Informasi tugas, seperti judul, catatan, kategori, prioritas, deadline, dan
sub-tugas, serta preferensi aplikasi disimpan di penyimpanan lokal perangkat.
Data tersebut tetap berada di perangkat kecuali pengguna memilih untuk
membagikan atau mencadangkannya.

## Notifikasi dan izin

Jika diaktifkan, TodO menggunakan izin notifikasi dan alarm Android untuk
menampilkan pengingat tugas serta ringkasan harian atau mingguan. Konten
notifikasi dibuat dari data yang tersimpan di perangkat. Pengguna dapat mengubah
izin ini melalui Pengaturan Android.

## Cadangan dan berbagi

Pengguna dapat memilih mengekspor cadangan JSON dan menyimpannya atau
membagikannya melalui aplikasi lain. Setelah dibagikan, penanganan file tunduk
pada kebijakan layanan atau aplikasi tujuan. TodO tidak mengirim cadangan
tersebut ke pengembang.

## Penyimpanan dan penghapusan

Data aplikasi tersimpan di perangkat. Menghapus data aplikasi atau mencopot TodO
dapat menghapus data lokal. Cadangan yang telah diekspor perlu dihapus terpisah
dari lokasi penyimpanannya.

## Privasi anak

TodO adalah aplikasi produktivitas umum dan tidak secara khusus ditujukan untuk
mengumpulkan informasi pribadi anak-anak.

## Perubahan kebijakan

Kebijakan ini dapat diperbarui jika perilaku aplikasi berubah. Versi terbaru
akan disediakan pada halaman distribusi aplikasi.
